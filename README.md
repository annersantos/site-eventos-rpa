# 🎉 R.P.A Produções Eventos e Festas — Website Oficial

> Landing Page One-Page institucional, responsiva e de alta performance desenvolvida para a **R.P.A Produções Eventos e Festas**, salão de festas e organização de eventos localizado em São Paulo - SP.

---

## 🚀 Visão Geral

O projeto foi construído com foco em **experiência do usuário (UX)**, **alta conversão** e **máxima performance mobile**. Possui navegação suave, integração direta de orçamentos via WhatsApp, galeria interativa e estrutura totalmente semântica com suporte a SEO local (Schema.org).

### 🌟 Destaques do Projeto
- **100% Nativo & Leve:** Construído exclusivamente com **HTML5, CSS3, JavaScript Vanilla e Tailwind CSS v4**, sem sobrecarga de frameworks JS pesados.
- **Ultra Otimizado para Mobile:** Imagens em formato moderno `.webp` com compressão avançada, lazy loading nativo e eliminação de gargalos de GPU (`backdrop-filter`).
- **Captação Direta de Leads:** Formulário com validação em tempo real e redirecionamento formatado para atendimento no WhatsApp.
- **Acessibilidade & SEO:** Marcação semântica com Open Graph, Twitter Cards e Schema.org (`EventVenue`).

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
| :--- | :--- |
| **HTML5** | Estrutura semântica, metatags de SEO e acessibilidade (ARIA). |
| **Tailwind CSS v4 + CSS3** | Estilização moderna, design system com tokens de cores e componentes customizados. |
| **JavaScript (Vanilla)** | Lógica de formulário, animações de scroll, menu responsivo, lightbox e FAQ. |
| **WebP & Picture Element** | Formato de imagem moderno de alta densidade e baixo peso de download. |

## ⚡ Como Executar o Projeto Localmente

Como o projeto é estático e independente, não necessita de instalação de servidores ou dependências para visualização:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/annersantos/site-eventos-rpa.git
   cd site-eventos-rpa
   ```

2. **Abra o projeto:**
   - Dê um duplo clique no arquivo `index.html`, ou
   - Use a extensão **Live Server** no VS Code.

## 🌐 Deploy e Hospedagem

O site está pronto para publicação imediata em qualquer plataforma estática:
- **GitHub Pages:** Acesse *Settings > Pages* no repositório do GitHub e selecione a branch `main` como fonte.
- **Vercel / Netlify / Cloudflare Pages:** Basta conectar o repositório do GitHub e o deploy será automático.
